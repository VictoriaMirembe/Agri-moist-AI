# User research

**Status: not yet done.** This file is where Evans records notes from talking to an
extension officer or farmer (TASKS.md T06, T33) and the 1-2 changes that come out of
it (T34). No interview has been conducted yet in this build session - the system
below was built from the written brief (RULES.md, DESIGN.md, the hackathon track
page) and the team's own judgement, not from a live conversation with an officer.

This is an honest gap, not a hidden one: DESCRIPTION.md and the submission are
expected to name who was actually consulted before the deadline, and to say nothing
that didn't happen (RULES.md section 4).

## Template for the actual interview

- **Who:** name/role, district, date.
- **What they do today** without this tool (paper, memory, WhatsApp groups, etc).
- **What they'd change** about the Visit form, the Approval queue wording, or the
  farmer-facing screens.
- **What we changed** in the build because of it (list the task IDs in TASKS.md).
